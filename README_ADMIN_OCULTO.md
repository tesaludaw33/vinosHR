# VINOS HR - Index con administrador oculto

Este paquete reemplaza el sistema con token de GitHub por un administrador oculto dentro del mismo `index.html`.

## Cómo entrar al admin

Abre tu página y usa una de estas opciones:

- Escribe `admin` con el teclado mientras estás en la página.
- O haz 5 clics rápidos sobre el logo `VINOS HR`.
- O abre la URL con `?admin=1` al final.

Ejemplo:
`https://tesaludaw33.github.io/vinosHR/?admin=1`

## Cómo publicar cambios

1. Entra al admin oculto.
2. Edita las sedes.
3. Pulsa `Descargar index actualizado`.
4. En GitHub, sube ese `index.html` a la raíz del repositorio y reemplaza el actual.
5. Haz `Commit changes`.

No necesitas token. La limitación es que la publicación para todos se hace subiendo el `index.html` actualizado a GitHub.
