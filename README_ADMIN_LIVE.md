# VINOS HR - index con admin oculto en vivo

Este `index.html` incluye un panel oculto dentro de la misma página.

## Abrir admin
- Abre `?admin=1` al final de la URL, o
- escribe `admin` en la página, o
- haz 5 clics rápidos sobre el logo.

## Qué permite
- Agregar sedes
- Editar nombre, WhatsApp e icono
- Ocultar/mostrar sedes con el checkbox Visible
- Eliminar sedes
- Cambiar sede destacada
- Ver los cambios en vivo en la página mientras editas

## Publicar para todos
Como GitHub Pages es una web estática, los cambios en vivo quedan primero en tu navegador.
Para publicarlos para todos:
1. Pulsa `Descargar index actualizado`.
2. Sube ese `index.html` a GitHub reemplazando el anterior.
3. Haz `Commit changes`.
