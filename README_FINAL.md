## Qué hacer

1. Sube `index.html` a tu repositorio `tesaludaw33/vinosHR` reemplazando el anterior.
2. Haz commit en `main`.
3. Abre la página: https://tesaludaw33.github.io/vinosHR/
4. Abre el admin oculto: https://tesaludaw33.github.io/vinosHR/?admin=1
5. Usa el PIN definido en `Code.gs`, edita sedes y pulsa `Guardar y publicar para todos`.

Si cambias el código de Apps Script más adelante, recuerda usar `Implementar > Gestionar implementaciones > Editar > Nueva versión` para que los cambios se apliquen a la URL `/exec`.
